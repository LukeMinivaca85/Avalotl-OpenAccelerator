# Open Accelerator Stack

## Avalotl OpenAccelerator

Top-level accelerator architecture and system integration.

## OpenHBM

HBM4 controller, protocol models, verification and memory-side architecture.

## OpenROAD

Open-source physical-design engine used for RTL-to-GDS implementation.

## GT2N

Experimental 2 nm nanosheet/GAAFET research PDK.

## GT2N-SI

Experimental integration work extending GT2N toward reproducible physical implementation.

## Design philosophy

No single repository needs to solve the entire semiconductor stack.

This project connects independent open-source components through stable interfaces.

The long-term objective is a reproducible path:

RTL → simulation → synthesis → physical design → verification → experimental GDSII
